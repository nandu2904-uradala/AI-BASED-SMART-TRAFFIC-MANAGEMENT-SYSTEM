# AI BASED SMART TRAFFIC MANAGEMENT SYSTEM
 This project simulates an AI-based traffic control system where traffic signals dynamically adjust based on vehicle density and emergency detection. It uses computer vision-inspired detection zones, prioritizes emergency vehicles, and includes collision avoidance and adaptive signal switching. The system mimics real-world intelligent transportation systems using JavaScript-based simulation. The system monitors traffic density, detects emergency vehicles, and adjusts signal timings automatically to optimize traffic movement and reduce congestion.
